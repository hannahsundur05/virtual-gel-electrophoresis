🧬 Virtual Agarose Gel Electrophoresis

I built this small interactive project to understand and visualize how DNA fragments separate during agarose gel electrophoresis.

Instead of just looking at a diagram in a textbook, this simulator lets you enter different DNA fragment sizes and see their bands appear on a virtual gel.

 🔬 What can it do?

- Enter DNA fragment sizes in bp
- Run a simple gel electrophoresis simulation
- Visualize the DNA bands after separation
- Experiment with different fragment sizes

💻 Technologies Used

- HTML
- CSS
- JavaScript

 🧪 How to Use

1. Enter the DNA fragment sizes separated by commas.
2. Click **Run Gel**.
3. The simulator will display the corresponding DNA bands.

For example:

`500, 1000, 1500, 2000`

 🎓 Why I Made This

As a biotechnology student interested in bioinformatics and computational biology, I wanted to connect a basic molecular biology technique with programming.

This project helped me understand how biological concepts can be represented through simple interactive software.

🚀 What I Learned

While building this project, I practiced working with HTML, CSS and JavaScript, handling user input, and creating a visual representation of DNA fragment separation.

More improvements can be added in the future, such as a DNA ladder, animations and more realistic gel parameters.
